# Changelog

All notable Thrilla-zilla changes are recorded here. Versions remain pre-1.0 until every promised core function works on the target devices.

## 0.1.0-alpha.2 — 2026-08-12

- Publish the first complete source and project record.
- Add a plain-language project overview, canonical requirements, donor-library record, ordered roadmap, status report, and contribution rules.
- Treat Ctrl+C as Back in submenus and as a clean Exit in the main menu.
- Add regression tests for Ctrl+C in both interactive and line-mode menus.
- Preserve the colored, phone-responsive interface and numeric-menu fallback.

## 0.1.0-alpha.1 — 2026-08-12

- Add the first Thrilla-native control shell.
- Add a compact colored menu for Termux and Windows terminals.
- Add cyan user text, green Thrilla responses, and semantic status colors.
- Add deterministic request routing with explanations.
- Add an OpenAI-compatible local-model client with remote endpoints blocked by default.
- Add the canonical Phase-1 catalog of 100 donors and the priority 30.
- Register XTLS/Xray-core as the first verified Phase-2 specialist.
- Add local conversation history, metadata-only activity logs, settings, diagnostics, and phone/Windows installers.
- Add Python 3.9 compatibility and standard-library regression tests.
